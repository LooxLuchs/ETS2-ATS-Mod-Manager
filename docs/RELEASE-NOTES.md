Version 0.5.2 of ETS2-ATS-Mod-Manager for native Pterodactyl v2 extensions. This is an early development release. Development, implementation, documentation and automated tests were AI-assisted; 0.5.0 was the project's first release.

This update removes the blue game/server-packages label above the Mod Manager heading. The project and build commands now live directly at the repository root.

Download the `.pteroext` package and its `.sha256` file from the assets below. The repository README explains installation, egg configuration, presets, load-order editing and Console Quick Switcher usage. The changelog describes the release features.

This package is MIT licensed; the license is included in the download. The build validates the frontend, PHP scenarios and Panel HTTP integration with simulated Wings operations before packaging. Game compatibility has not yet been verified against a real ETS2/ATS server. Removing mods is experimental and preserves the DAT map data.
